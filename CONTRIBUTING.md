# Как контрибьютить в проект

Рад любой помощи. Чтобы всем было комфортно, придерживаемся простых правил.

## Локальная установка
1. Сделай fork репозитория и склонируй себе.
2. Создай и активируй виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
3. Установи фреймворк в режиме редактирования вместе со всеми инструментами для разработки:   
    ```bash
    pip install -e ".[dev]"
    ```
4. Создай новую ветку под свою задачу. Называй логично, например feature/название-фичи или fix/суть-бага:
    ```bash
    git checkout -b feature/cool-new-stuff
    ```

## Кодстайл и проверки
Используем `ruff` для линтинга и `mypy` для статической типизации. Перед тем как открывать merge request, обязательно прогони:

* **Форматирование и линтинг:** `ruff check .` и `ruff format .`
* **Проверка типов:** `mypy .` - но тут по желанию
* **Тесты:** `pytest`

Не стесняйся открывать merge request даже с ошибками, на CI прогоним все тесты и потом просто пофиксишь ты или кто-то другой
